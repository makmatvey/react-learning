# Задача 01 — День 1: ES6 перед React

**Время:** ~45–60 мин (после 10–15 мин теории в чате).  
**Файл решения:** `tasks/task-01.mjs`

## Цель

Закрепить модули, деструктуризацию, spread и цепочку `map` / `filter` / `reduce` на одной маленькой задаче про «пользователей» — без React.

## Условие

Дан массив объектов пользователей (уже в `task-01.mjs`). Нужно дописать функции в этом же файле:

1. **`pickActive(users)`** — вернуть **новый** массив только с `isActive: true` (без мутации исходного).
2. **`formatNames(users)`** — через `map` вернуть массив строк вида `` `${firstName} ${lastName}` ``.
3. **`totalAge(users)`** — через `reduce` сумму полей `age`.
4. **`summarizeActive(users)`** — одна цепочка: активные → имена → **одна** строка через `join(', ')` (можно вызывать свои функции или писать цепочку inline).
5. **`withDefaults({ firstName, lastName, ...rest })`** — деструктуризация параметра + spread: вернуть объект `{ firstName, lastName, isActive: true, ...rest }` (если `isActive` уже в `rest`, он перезапишется на `true` — так и задумано).

Внизу файла есть блок `runChecks()` — после реализации запуск:

```bash
node tasks/task-01.mjs
```

В консоли должно быть `Все проверки пройдены ✅` (или аналогичный вывод из заготовки).
